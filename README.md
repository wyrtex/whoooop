# Pulsar

Приложение для iPhone и Apple Watch в духе WHOOP: **восстановление**, **нагрузка**, **сон**, **стресс** и **биологический возраст**. Данные берутся из Apple Health, то есть с Apple Watch. Все расчёты выполняются на устройстве.

## Возможности

### iPhone
- **Обзор**: три кольца «Сон / Восстановление / Нагрузка», переключение по дням, советы коуча, цель по нагрузке, список активностей за день, монитор стресса, ключевые показатели (ВСР, пульс покоя, дыхание, SpO₂, температура кожи, калории, шаги), запуск тренировки на часах.
- **Восстановление 0–100 %** (зелёное / жёлтое / красное): из чего сложилась оценка, рекомендованная нагрузка, графики восстановления, ВСР и пульса покоя за 30 дней.
- **Нагрузка 0–21**: график накопления нагрузки за день с целевым коридором, пульс, время в пульсовых зонах, калории, разбор каждой тренировки (нагрузка, средний и максимальный пульс, зоны, дистанция).
- **Сон**: гипнограмма, стадии, эффективность, регулярность, восстанавливающий сон, пробуждения, частота дыхания, потребность во сне (база + нагрузка + долг − дневной сон), планировщик отбоя в трёх вариантах: «Пик», «Норма» и «Минимум».
- **Монитор стресса 0–3**: график за день и распределение по уровням.
- **Тренды**: десять метрик за 7, 30 или 60 дней, сравнение с предыдущим периодом, недельный отчёт.
- **Дневник**: привычки (алкоголь, кофеин, поздний ужин, медитация, сауна и т. д.) и их влияние на восстановление на следующее утро.
- **Здоровье**: монитор показателей относительно личной нормы, биологический возраст с разбором факторов, форма (VO₂max, кардио-минуты).
- **Профиль**: возраст, пол, вес, рост, максимальный пульс, потребность во сне, время подъёма.

### Apple Watch
- Сводка дня: кольцо восстановления, сон, нагрузка.
- «Сейчас»: последний пульс, текущий уровень стресса, нагрузка относительно цели.
- Тренировки (бег, ходьба, велосипед, силовая, ВИИТ, гребля и др.): живой пульс, текущая зона, нагрузка тренировки и дня в реальном времени, калории, дистанция, зоны, пауза и итог. Тренировка записывается в Apple Health.
- Тренировку можно запустить с iPhone, кнопкой «Начать на часах».
- iPhone передаёт на часы сводку дня через WatchConnectivity. Без телефона часы считают её сами.

## Как считается

Алгоритмы WHOOP закрыты, поэтому здесь используются собственные приближения (`Shared/Engine`):

| Метрика | Расчёт |
|---|---|
| Нагрузка | TRIMP Банистера по резерву ЧСС (засчитывается от 30 % резерва), шкала `21 × (1 − e^(−TRIMP/100))` |
| Восстановление | z-оценки к личной 30-дневной норме: ВСР (55 %), пульс покоя (25 %), дыхание, SpO₂, температура плюс качество сна, затем логистическая функция |
| Потребность во сне | база + до 45 мин за нагрузку + взвешенный долг за 3 ночи (до 2 ч) − дневной сон |
| Регулярность сна | стандартное отклонение времени засыпания и подъёма за 4 ночи |
| Стресс | превышение пульса покоя в 15-минутных интервалах, без сна и тренировок |
| Биовозраст | поправки к паспортному возрасту за VO₂max, пульс покоя, ВСР, сон, регулярность, шаги и кардио-минуты |

Пока личная норма не сформировалась (первые 3–4 дня), используются популяционные значения.

## Сборка

IPA собирается в GitHub Actions (`.github/workflows/build.yml`) при каждом пуше:

1. Откройте **Actions → Build IPA → последний запуск**.
2. Скачайте артефакт **Pulsar-ipa**: это zip, внутри лежит `Pulsar.ipa`.
3. Если запушить тег `v*` (например, `v1.0.0`), IPA появится в GitHub Releases.

IPA собирается **без подписи** (ad-hoc, с entitlements HealthKit), поэтому перед установкой её нужно подписать своим Apple ID.

### Локально (macOS)
```bash
brew install xcodegen
xcodegen generate
open Pulsar.xcodeproj
```
В Xcode выберите свою команду (Signing & Capabilities) для обоих таргетов, `Pulsar` и `PulsarWatch`, и запустите на iPhone.

## Установка на iPhone и Apple Watch

1. Подпишите и установите `Pulsar.ipa` через **Sideloadly**, **AltStore** или **Xcode**. Подойдёт бесплатный Apple ID: в этом случае приложение придётся переподписывать раз в 7 дней.
2. На iPhone откройте Pulsar и нажмите «Подключить Apple Health», затем разрешите доступ.
3. Часы: откройте на iPhone приложение **Watch → Мои часы → Доступные приложения** и нажмите «Установить» напротив Pulsar. Можно также включить «Автоустановку приложений».
4. На часах откройте Pulsar и разрешите доступ к Здоровью.

> Чтобы часы установили встроенное приложение, оно должно быть подписано тем же сертификатом, что и приложение для iPhone. Xcode и Sideloadly подписывают вложенное приложение для часов. Если какой-то инструмент установки его пропускает, соберите проект через Xcode со своим Apple ID: это самый надёжный способ.

Для точных данных включите на часах отслеживание сна («Здоровье → Сон → Режим сна»), измерение кислорода в крови и носите часы и днём, и ночью.

## Структура

```
project.yml            — описание проекта для XcodeGen
Shared/                — общий код iPhone и часов
  Models/              — модели данных
  Engine/              — расчёты: Strain, Recovery, Sleep, Stress, Healthspan, Coach, MetricsBuilder
  Health/              — чтение HealthKit
  Store/               — хранилище и кэш
  Sync/                — синхронизация iPhone ↔ часы
  UI/                  — тема, форматирование, кольца
iOS/                   — приложение для iPhone
Watch/                 — приложение для Apple Watch
scripts/make_icon.py   — генератор иконки
```

Название меняется в `project.yml` (`CFBundleDisplayName`, bundle id). Pulsar не является медицинским изделием.
