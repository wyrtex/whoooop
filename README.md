# Pulsar

Приложение для iPhone и Apple Watch в духе WHOOP: **восстановление**, **нагрузка**, **сон**, **стресс** и **биологический возраст**. Данные берутся из Apple Health, то есть с Apple Watch. Все расчёты выполняются на устройстве.

## Возможности

### iPhone
- **Обзор**: три кольца «Сон / Восстановление / Нагрузка», переключение по дням, советы коуча, цель по нагрузке, список активностей за день, монитор стресса, ключевые показатели (ВСР, пульс покоя, дыхание, SpO₂, температура кожи, калории, шаги), запуск тренировки на часах.
- **Восстановление 0–100 %** (зелёное / жёлтое / красное): из чего сложилась оценка, рекомендованная нагрузка, графики восстановления, ВСР и пульса покоя за 30 дней.
- **Нагрузка 0–21**: график накопления нагрузки за день с целевым коридором, пульс, время в пульсовых зонах, калории, разбор каждой тренировки (нагрузка, средний и максимальный пульс, зоны, дистанция).
- **Сон**: гипнограмма, стадии, эффективность, регулярность, восстанавливающий сон, пробуждения, частота дыхания, потребность во сне (база + нагрузка + долг − дневной сон), планировщик отбоя в трёх вариантах: «Пик», «Норма» и «Минимум».
- **Монитор стресса 0–3**: график за день и распределение по уровням.
- **Тренды**: десять метрик за 7, 30 или 60 дней, сравнение с предыдущим периодом, недельный отчёт.
- **Дневник**: привычки (алкоголь, кофеин, поздний ужин, медитация, сауна и т. д.) и их влияние на восстановление на следующее утро.
- **Здоровье**: монитор показателей относительно личной нормы, биологический возраст с разбором факторов, форма (VO₂max, кардио-минуты).
- **Профиль**: возраст, пол, вес, рост, максимальный пульс, потребность во сне, время подъёма.

### Похудение
- **Взвешивания** (вечером, по желанию, с напоминанием в выбранное время). Вес сохраняется в «Здоровье», подтягивает данные с умных весов и синхронизируется с весом в профиле в обе стороны.
- **Журнал еды** со временем приёма, три режима:
  - *Описание*: «фасоль, брокколи и цветная капуста на 3/4 тарелки, большая куриная котлета». ИИ разложит блюдо на компоненты и посчитает граммы и КБЖУ.
  - *Точный продукт*: «Йогурт Активиа клубника 2,4% 130 г». ИИ найдёт продукт в интернете (Google Search) и покажет состав, КБЖУ на 100 г и на порцию, аллергены и источники.
  - *Вручную*: если калории известны, запрос к ИИ не нужен.
- **Баланс**: съедено − сожжено (активные и базовые калории с Apple Watch) → ± кг (7700 ккал ≈ 1 кг). Есть остаток калорий на день, прогноз к концу дня, недельный график, кривая веса «по калориям» рядом с фактическим весом и ориентировочная дата достижения цели.
- **План тренировок** против жира на животе: утром пресс/кор, вечером планка и функциональные упражнения, плюс кардио. Учитывает восстановление и пожелания. Упражнения отмечаются галочками. Без ключа работает базовый план.

#### Ключи Gemini и экономия запросов
- Ключ бесплатно выдаётся в [Google AI Studio](https://aistudio.google.com/apikey). Вводится в приложении: Похудение → ⚙︎ → «Ключи Gemini». Хранится в Keychain на iPhone. Можно добавить несколько ключей.
- **Ключи не хранятся в GitHub и не встраиваются в IPA из Actions.** Артефакты публичного репозитория может скачать любой пользователь GitHub, и ключ легко достать из IPA. GitHub Secrets скрывают ключ в репозитории и логах, но не в собранном приложении. Поэтому публичная сборка ключей не содержит.
- Для личной сборки в Xcode ключи можно положить в `.secrets/gemini_keys` (он в `.gitignore`). Такую IPA никому не передавайте.
- Если модель вернула ошибку (не найдена, перегружена), берётся следующая модель из списка. Если у ключа кончился лимит (429), берётся следующий ключ. Блокировки запоминаются (дневные лимиты — до сброса в полночь по тихоокеанскому времени), поэтому запросы на заведомо недоступные пары не тратятся.
- Экономия: одинаковые блюда берутся из кэша, кнопка «Повторить» добавляет недавнюю еду без запроса, план хранится на устройстве и пересоставляется только по кнопке, ответы — компактный JSON с ограничением длины, «размышления» модели отключены.
- В настройках видно число запросов и токенов за сегодня, а список моделей можно менять.

### Apple Watch
- Сводка дня: кольцо восстановления, сон, нагрузка.
- «Сейчас»: последний пульс, текущий уровень стресса, нагрузка относительно цели.
- Тренировки (бег, ходьба, велосипед, силовая, ВИИТ, гребля и др.): живой пульс, текущая зона, нагрузка тренировки и дня в реальном времени, калории, дистанция, зоны, пауза и итог. Тренировка записывается в Apple Health.
- Тренировку можно запустить с iPhone, кнопкой «Начать на часах».
- iPhone передаёт на часы сводку дня через WatchConnectivity. Без телефона часы считают её сами.

### Виджеты
Есть для рабочего стола и экрана блокировки iPhone и для циферблатов Apple Watch:

| Виджет | iPhone | Apple Watch |
|---|---|---|
| **Обзор дня**: три кольца (восстановление, нагрузка, сон) | маленький, средний (+ВСР, пульс покоя, стресс), большой (+6 показателей и совет коуча), экран блокировки | круглый (вложенные кольца), прямоугольный, строка |
| **Восстановление** | маленький, экран блокировки | круглый, угловой, прямоугольный, строка |
| **Нагрузка** (с целью) | маленький, экран блокировки | круглый, угловой, прямоугольный, строка |
| **Сон** (качество и часы) | маленький, экран блокировки | круглый, угловой, прямоугольный, строка |
| **Стресс** | маленький, экран блокировки | круглый, угловой, прямоугольный, строка |
| **Показатели здоровья**: ВСР, пульс покоя, дыхание, SpO₂, стресс, шаги | маленький, средний, экран блокировки | прямоугольный, круглый, строка |
| **Свои показатели**: 4 на выбор из 11 | маленький (2×2), средний (4 кольца), экран блокировки | прямоугольный, круглый, угловой, строка + готовые наборы |

Чтобы выбрать показатели в виджете «Свои показатели», удерживайте виджет и нажмите «Изменить виджет». На часах при выборе complication предлагаются готовые наборы.

Виджеты не зависят от приложения: они сами читают данные Apple Watch из «Здоровья», считают сводку тем же движком и хранят последний результат у себя. Поэтому они работают и без App Group, например при подписи через eSign. Источники обновления:
- запрос к системе каждые 3 минуты (iOS может откладывать его ради экономии батареи);
- кнопка ↻ в средних и больших виджетах: обновляет данные, не открывая приложение;
- кнопка «Обновить виджеты» в профиле и любое обновление данных в приложении.

Пока iPhone заблокирован, «Здоровье» закрыто для чтения, и виджет показывает последние известные данные. Если день сменился, а свежих данных ещё нет, вчерашние значения показываются приглушёнными.

## Как считается

Алгоритмы WHOOP закрыты, поэтому здесь используются собственные приближения (`Shared/Engine`):

| Метрика | Расчёт |
|---|---|
| Нагрузка | TRIMP Банистера по резерву ЧСС (засчитывается от 30 % резерва), шкала `21 × (1 − e^(−TRIMP/100))` |
| Восстановление | z-оценки к личной 30-дневной норме: ВСР (55 %), пульс покоя (25 %), дыхание, SpO₂, температура плюс качество сна, затем логистическая функция |
| Потребность во сне | база + до 45 мин за нагрузку + взвешенный долг за 3 ночи (до 2 ч) − дневной сон |
| Регулярность сна | стандартное отклонение времени засыпания и подъёма за 4 ночи |
| Стресс | превышение пульса покоя в 15-минутных интервалах, без сна и тренировок |
| Биовозраст | поправки к паспортному возрасту за VO₂max, пульс покоя, ВСР, сон, регулярность, шаги и кардио-минуты |

Пока личная норма не сформировалась (первые 3–4 дня), используются популяционные значения.

## Сборка

IPA собирается в GitHub Actions (`.github/workflows/build.yml`) при каждом пуше:

1. Откройте **Actions → Build IPA → последний запуск**.
2. Скачайте артефакт **Pulsar-ipa**: это zip, внутри лежит `Pulsar.ipa`.
3. Если запушить тег `v*` (например, `v1.0.0`), IPA появится в GitHub Releases.

В артефакте две сборки:
- **`Pulsar.ipa`**: только iPhone с виджетами. Подходит для eSign и сертификатов, в которых нет профиля для часов. Метрики всё равно считаются по данным Apple Watch из «Здоровья», приложение на часах для этого не нужно.
- **`Pulsar-with-watch.ipa`**: плюс приложение и виджеты для Apple Watch. Нужна подпись, которая покрывает и часы: Xcode с Apple ID или Sideloadly.

IPA собирается **без подписи** (ad-hoc, с entitlements HealthKit), поэтому перед установкой её нужно подписать своим Apple ID.

### Локально (macOS)
```bash
brew install xcodegen
xcodegen generate
open Pulsar.xcodeproj
```
В Xcode выберите свою команду (Signing & Capabilities) для обоих таргетов, `Pulsar` и `PulsarWatch`, и запустите на iPhone.

## Установка на iPhone и Apple Watch

1. Подпишите и установите `Pulsar.ipa` через **Sideloadly**, **AltStore** или **Xcode**. Подойдёт бесплатный Apple ID: в этом случае приложение придётся переподписывать раз в 7 дней.
2. На iPhone откройте Pulsar и нажмите «Подключить Apple Health», затем разрешите доступ.
3. Часы: откройте на iPhone приложение **Watch → Мои часы → Доступные приложения** и нажмите «Установить» напротив Pulsar. Можно также включить «Автоустановку приложений».
4. На часах откройте Pulsar и разрешите доступ к Здоровью.

> Если часы пишут «не удалось проверить целостность», значит сертификат не подписал приложение для часов. Ставьте `Pulsar.ipa`.

> App Group желателен, но не обязателен. Xcode со своей командой создаст его сам (Signing & Capabilities → App Groups). Sideloadly и AltStore переподписывают группы автоматически. Если виджет пишет «Откройте Pulsar», хотя приложение уже открывалось, значит группа не подписалась: соберите проект через Xcode.

> Чтобы часы установили встроенное приложение, оно должно быть подписано тем же сертификатом, что и приложение для iPhone. Xcode и Sideloadly подписывают вложенное приложение для часов. Если какой-то инструмент установки его пропускает, соберите проект через Xcode со своим Apple ID: это самый надёжный способ.

Для точных данных включите на часах отслеживание сна («Здоровье → Сон → Режим сна»), измерение кислорода в крови и носите часы и днём, и ночью.

## Структура

```
project.yml            — описание проекта для XcodeGen
Shared/                — общий код iPhone и часов
  Models/              — модели данных
  Engine/              — расчёты: Strain, Recovery, Sleep, Stress, Healthspan, Coach, MetricsBuilder
  Health/              — чтение HealthKit
  Store/               — хранилище и кэш
  Sync/                — синхронизация iPhone ↔ часы
  Snapshot/            — общая с виджетами сводка (App Group)
  UI/                  — тема, форматирование, кольца
iOS/                   — приложение для iPhone
  Loss/                — вкладка «Похудение», клиент Gemini
Watch/                 — приложение для Apple Watch
Widgets/               — виджеты (общий код для iPhone и часов)
Config/                — entitlements расширений виджетов
scripts/make_icon.py   — генератор иконки
```

Название меняется в `project.yml` (`CFBundleDisplayName`, bundle id). Pulsar не является медицинским изделием.
